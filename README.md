# 🎞️ ffmpeg-abr-packager

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Format: HLS](https://img.shields.io/badge/Streaming-HLS%20ABR-blueviolet.svg)](https://github.com/MobileConduit)

Industrial-grade automation script converting master videos into multi-bitrate HLS ladders (1080p, 720p, 480p, 360p) with synchronized GOP boundaries and unified `master.m3u8` manifest ready for CDN distribution.

## 🚀 Usage
```bash
python packager.py --input master_feature.mp4 --output /var/www/cdn/hls/movie1
```
